# Advocacy-published facility exports go here

Two sources, both published by researchers or campaigners rather than by
regulators. That is not a lesser class of evidence: Farm Transparency's list is
built from freedom-of-information requests and public licence registers, and
Global BioLabs is a King's College London and Schar School project. Each record
this harvester writes names where its claim comes from, which is the same
treatment AAALAC gets for being voluntary and APHIS gets for registering
entities rather than buildings.

## Global BioLabs

    https://www.globalbiolabs.org/map

BSL4 and BSL3+ laboratories worldwide, operating and planned. Download the
dataset and drop the CSV in this folder. This is the only global account of
high-containment laboratories: there is no international register and no
obligation to declare one.

## Farm Transparency Project

    https://www.farmtransparency.org/facilities/experimentation

Australian animal-research facilities with addresses and licence detail.
Australia publishes no facility register, so without this there is nothing at
all for the country.

## Notes

Any number of CSVs, either source, any column spellings - the harvester matches
column names loosely and decides which source a row came from by its content
rather than by the filename. It prints the columns it found, so a file it cannot
read says why.
